Формат выдачи Один профиль → один корректный результат: APK для монолитной доставки или APKS для split-доставки.

Google Play delivery

Полученные варианты

Успешных профилей: 0. Для каждого профиля выдаётся один APK либо один APKS; отдельные split APK показаны только как состав набора.

Неуспешные профили


    

      
01
Точный package lookup
Полный package name или ссылка Google Play не смешиваются с обычной поисковой выдачей.

      
02
Rate-friendly поиск
Debounce, AbortController и session cache позволяют подсказкам и основной выдаче переиспользовать один FDFE search.

      
03
APK или APKS
Монолитная доставка скачивается одним APK. Split-доставка собирается в APKS из base + ABI/density/language/feature splits.

      
04
Оригинальные подписи
APK внутри APKS не перепаковываются и не переподписываются: сохраняются оригинальные Google Play артефакты.
