Источник файлов — Google Play. Cloudflare Worker используется только как серверный транспорт к приватному Android FDFE и для передачи временных Google download cookies. APK не хранятся на проекте.

Регион и конфигурация

Для каждого выбранного профиля выполняется details → purchase → delivery. Доступность зависит от anonymous account, региона, device profile и staged rollout.

Полученные варианты

Успешных профилей: 0. Можно скачать каждый оригинальный файл отдельно или собрать APK-набор в .apks.

Неуспешные профили


    

      
01
Точный package lookup
Полный package name или ссылка Google Play не смешиваются с обычной поисковой выдачей.

      
02
Rate-friendly поиск
Debounce, AbortController и session cache позволяют подсказкам и основной выдаче переиспользовать один FDFE search.

      
03
Split APK
Отображаются base APK, config splits и дополнительные delivery-файлы, которые Google реально отдал выбранному профилю.

      
04
APKS локально
Браузер собирает SAI-compatible .apks из оригинальных APK; файлы не переподписываются и не модифицируются.
